# Bioquest

Open `index.html` in a modern browser.

## Project files
- `index.html` — website structure
- `style.css` — presentation and layout
- `script.js` — game, quizzes, map, and navigation logic
- `assets/` — backgrounds, sprites, fonts, and audio

## Music
The supplied MP3 is used only while the Game or Map section is open. Leaving those sections pauses and resets the track; entering either section starts it from the beginning. Browser autoplay restrictions may require the first click/tap before playback is permitted.

## Notes
The existing quiz content and scoring assignments have been preserved. Map pin positioning and sector filter matching have been corrected without changing the opportunity records.
