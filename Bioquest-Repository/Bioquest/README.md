# Bioquest Integrated Campus

## Directory Structure
```
Bioquest/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── backgrounds/
    │   └── biotech-campus-background.png
    ├── sprites/
    │   └── character-placeholder.svg
    └── fonts/
        └── VCR_OSD_MONO_1.001.ttf
```

## How to Run
Keep `index.html`, `style.css`, `script.js`, and the `assets/` directory together. Open `index.html` in any web browser.
